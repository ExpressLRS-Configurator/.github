## Что такое ExpressLRS Configurator

**ExpressLRS Configurator** — официальная кроссплатформенная утилита для прошивки и настройки радиосистем на базе **ExpressLRS**.  
ExpressLRS — это открытый протокол долгой дальности (LR) с низкой задержкой, разработанный специально для FPV-дронов, коптеров, RC-платформ, роботов и беспилотных систем.

Configurator упрощает обновление модулей, приёмников, установку Wi-Fi прошивки, OTA обновления, настройку параметров телеметрии и привязку под конкретные частотные диапазоны.  
Программа автоматизирует весь процесс прошивки и исключает ошибки, возникающие при ручной компиляции в Arduino/VS Code.

## Основные возможности

- 📡 Поддержка прошивки **TX-модулей и RX-приёмников** ExpressLRS
- 🔄 **OTA Wi-Fi обновление** без кабеля
- 🔧 Полный доступ к настройкам протокола (LQ, TX Power, Packet Rate)
- 🧭 Выбор частотных систем **2.4 GHz / 868 MHz / 915 MHz**
- ⚙️ Авто-генерация конфигурации для конкретного железа
- 🔍 Диагностика состояния и проверка привязки
- 🧠 Совместимость с **OpenTX/EdgeTX/Betaflight/INAV**
- 📥 Загрузка и установка прошивок из официальных репозиториев

- 🧩 Настройка LUA-скриптов для аппаратуры RC

## Как начать

1. Подключите модуль/приёмник USB или подключитесь к нему через Wi-Fi  
2. Запустите программу и выберите модель оборудования  
3. Настройте частоту, мощность, скорость пакета  
4. Нажмите **Build & Flash**  
5. Проверьте соединение LUA-скриптом на аппаратуре
