# .github
   ExpressLRS Configurator — официальная программа для прошивки и настройки модулей и приёмников ExpressLRS. Обеспечивает OTA Wi-Fi обновление, выбор частоты, мощности и скорости пакетов, диагностику связи и телеметрии, а также автоматическую установку прошивок из официальных репозиториев. Идеален для FPV-гонок и долгой дальности.
